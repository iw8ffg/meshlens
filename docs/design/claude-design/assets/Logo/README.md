# Logo

`meshlens-logo-attuale.svg` è il marchio in uso oggi, copiato senza modifiche (tre colori propri: `#14b8a6`, `#0f766e`, `#0ea5e9`, `#f59e0b`).

`meshlens-logo.svg` è l'evoluzione proposta, per fondi scuri: stessa idea (lente sopra una rete di nodi) con il reticolo ingrandito dentro la lente e il punto ambra al centro. `meshlens-logo-su-chiaro.svg` è la stessa versione per fondi chiari. Sono SVG a colori fissi: caricati con `<img>` non ereditano `currentColor`, quindi si sceglie il file giusto per il fondo.

`app-icon.svg` è l'icona dell'app da 64 px in su. `app-icon-piccola.svg` è la versione semplificata (solo lente e punto ambra) da usare a 16, 24 e 32 px, dove il reticolo non si legge.

Il marchio Meshtastic non è in questo gruppo: vedi la scheda MeshtasticBadge.
