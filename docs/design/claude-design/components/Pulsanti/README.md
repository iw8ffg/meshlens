I pulsanti avviano un'azione. Il consumatore fornisce etichetta (verbo all'infinito o imperativo breve: «Avvia prova», «Elimina») e, se serve, un'icona.

- Un solo pulsante principale (`accent`) per vista o modale.
- `danger` solo per azioni che cancellano o interrompono (Elimina, Ferma la prova, Applica una modifica a rischio).
- Il pulsante testo (`ghost`) serve per azioni terziarie dentro righe e banner.
- Altezza 32 px su desktop, 44 px su telefono; area toccabile mai sotto 44 px.
- Disabilitato: opacità ridotta, e spiega il motivo in un testo vicino.
- Focus visibile con `focus-ring`, 2 px.
