Radio collegate via USB o Bluetooth con stato, nodo locale, canali e chiave admin da copiare; dialogo per aggiungere una radio (porte COM con nome del dispositivo, oppure scansione Bluetooth). Stati: normale, aggiungi USB, aggiungi Bluetooth, nessuna radio, errore porta.

Usa i pulsanti Vista, Tema e Stato sopra l'anteprima per passare tra desktop e telefono, tema scuro e chiaro e i vari stati.
