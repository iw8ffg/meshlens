Elementi disegnati sulla mappa MapLibre: marker dei nodi, cluster, cerchio di precisione, collegamenti, tracce, punti Range Test, popup, legenda, controlli e indicatore offline.

- Marker: il riempimento dice l'ultimo contatto, l'anello dice la fonte; la stella ambra indica «Mio nodo».
- Collegamenti: linea di 3 px colorata per SNR; tratteggio solo per i traceroute.
- Posizione approssimata: cerchio tratteggiato `src-mqtt` col raggio dell'errore.
- Punto Range Test mancante: cerchio vuoto con croce.
- I controlli hanno 44 px su telefono; la legenda diventa un pulsante che si espande.
- Il fondo mappa usa `map-land`, `map-water`, `map-road`, `map-label` in entrambi i temi.
