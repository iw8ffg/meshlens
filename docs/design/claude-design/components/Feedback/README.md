Banner, toast, barre di avanzamento, stati vuoti e segnaposto di caricamento.

- Banner per ciò che resta (avvisi, errori di connessione, aggiornamenti); toast per un esito che sparisce dopo 5 s.
- Ogni stato porta titolo e icona oltre al colore.
- Lo stato vuoto dice cosa manca e offre l'azione per riempirlo.
- Il caricamento usa segnaposto fissi, senza animazione continua.
- Le barre di avanzamento mostrano sempre il numero accanto («38%», «3/25»).
