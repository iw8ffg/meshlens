Le icone sono SVG a tratto di 1,75 px su griglia 24, colorate con `currentColor`. Il set mostrato è un segnaposto nello stile di Lucide: in produzione usa Lucide (licenza ISC) con gli stessi nomi.

- Dimensione 16 px dentro badge e pulsanti, 18 px nei controlli, 20 px nelle liste, 24 px nella barra in basso.
- Sempre con etichetta di testo, tranne i pulsanti solo icona, che hanno `aria-label`.
- Niente emoji come icone o come stato.
- Le bandiere delle nazioni sono SVG (per esempio il pacchetto flag-icons, MIT), mai emoji: su Windows le emoji-bandiera si vedono come due lettere.
