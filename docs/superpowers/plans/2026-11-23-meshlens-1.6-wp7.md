## Fatti verificati sul codice (base del piano)

**A. Cosa salva davvero il registro pacchetti** (`S/packet_log.py`, `S/events.py`, tabella `packets`): la colonna `packets.raw` contiene **solo `Data.payload`** (decifrato se possibile, altrimenti i byte cifrati), troncato a `RAW_MAX = 256` byte; il `MeshPacket` completo NON è salvato. Le altre colonne: `time, from_num, to_num, packet_id, source, broker, radio_id, channel (testo: indice per RF, nome per MQTT), portnum (nome, es. "TEXT_MESSAGE_APP"), kind, status (ok|encrypted|unsupported|undecodable|empty), snr, rssi, hops, hop_start, hop_limit, relay_node, gateway, copies, size`. `size` è già `len(raw)` dopo il troncamento: un `raw` lungo esattamente 256 byte va trattato come **possibilmente troncato** e il pacchetto saltato dal registratore da DB. Il registro scrive solo con `packet_log_mode` = `archived` o `all` (predefinito `archived`: solo i pacchetti "archiviati"). Conseguenza: il registratore da DB **ricostruisce** un `MeshPacket` da colonne + payload (non un duplicato bit-a-bit); il registratore live, invece, registra i `FromRadio` veri.

**B. Lato client (libreria 2.7.11, `stream_interface.py`/`tcp_interface.py`/`mesh_interface.py`):**
- `TCPInterface.connect()` → `myConnect()` (socket) → `StreamInterface.connect()`: scrive **32 byte `0xC3`** (risveglio), dorme 0,1 s, avvia il thread lettore (legge **1 byte alla volta**: cerca `0x94`, poi `0xC3`, poi 2 byte di lunghezza big-endian, poi il corpo; lunghezza > `MAX_TO_FROM_RADIO_SIZE = 512` → riparte), poi `_startConfig()` che invia `ToRadio{want_config_id = N}` con `N` casuale 1..0xFFFFFFFF (`!= 69420`) e attende `isConnected`.
- Ogni scrittura del client (`_writeBytes`) dorme 0,1 s (1 s su Windows 11): i test d'integrazione sono lenti per natura, non farli ridondanti.
- `_handleFromRadio` è una catena `if/elif`: `my_info` → `metadata` → `node_info` → `config_complete_id == configId` → `channel` → `packet` → `log_record` → `queueStatus` → `clientNotification` → `mqttClientProxyMessage` → `xmodemPacket` → `rebooted` → `config`/`moduleConfig`. Attenzione: `config_complete_id` ha default 0, quindi `configId` casuale ≠ 0 evita falsi positivi; il server DEVE rimandare `config_complete_id == want_config_id` ricevuto.
- `waitForConfig` richiede che `myInfo` e `nodes` siano valorizzati e che `localNode.waitForConfig()` veda `localConfig`+`moduleConfig` (almeno un `config` e un `module_config` ricevuti), `_handleConfigComplete` chiama `localNode.setChannels(channels)` e `_connected()` (imposta `isConnected`, pubblica `meshtastic.connection.established`).
- `nodes` si riempie solo da `node_info` con `user.id` valorizzato (`!xxxxxxxx`). `localNode.nodeNum = my_info.my_node_num`.
- **Coda di invio:** per ogni `ToRadio.packet` la libreria tiene il pacchetto in `queue[id]` e lo **rispedisce a ogni successivo `_sendToRadio` finché non riceve un `FromRadio.queueStatus` con `mesh_packet_id == id` e `res == 0`**. La radio finta DEVE quindi rispondere con `queueStatus{res=0, free=…, maxlen=…, mesh_packet_id=id}` a ogni pacchetto, altrimenti ogni invio successivo duplica i precedenti. (Test dedicato.)
- `sendText(text, dest, wantAck=True, channelIndex)` costruisce `MeshPacket{to, id, channel, want_ack, hop_limit, priority=RELIABLE, decoded{portnum=TEXT_MESSAGE_APP, payload=utf8}}` dentro `ToRadio.packet`. `sendHeartbeat` invia `ToRadio.heartbeat` (da ignorare). `close()` invia `ToRadio.disconnect = true`.

**C. Lato MeshLens** (`S/radio.py`, `S/radio_manager.py`): una radio `kind="tcp"`, `address="127.0.0.1:N"` viene creata da `default_iface_factory` → `MeshLensTCPInterface(hostname, portNumber, timeout=TCP_CONFIG_TIMEOUT=45)` (connect con timeout 5 s, keepalive, niente riconnessione interna). `RadioConnector._connect` registra l'iface nell'hub, legge `iface.myInfo.my_node_num`, `iface.nodes[id].user.longName`, i canali da `iface.localNode.channels` (`read_channels`: ruolo ≠ DISABLED), emette gli eventi del nodedb (`nodedb_to_events`) e passa ogni `meshtastic.receive` a `on_packet` (→ `packet_to_event`/`packet_to_raw`). `parse_tcp_address` accetta `127.0.0.1:4404`. Per i pacchetti ricevuti, `packet_to_event` usa il dict della libreria (`decoded.portnum`, `decoded.text`/`payload`, `from`, `to`, `id`, `channel`, `rxSnr`, `hopStart`, `hopLimit`): la radio finta deve quindi mandare `MeshPacket` con `decoded` (testo, posizione, nodeinfo, telemetria) corretti. `_resolve` ignora un ack con `from == my_node_num` (resta "sent"); un ack con `from == destinatario` lo porta a "delivered".

## Handshake: sequenza esatta della radio finta

Il server mantiene per ogni client un buffer di ricezione con la stessa macchina a stati del lettore della libreria (scarta i byte finché non trova `0x94 0xC3`; i 32×`0xC3` iniziali vengono scartati naturalmente: `0xC3` non è `START1`).

**Ricezione di `ToRadio`** (decodificato con `mesh_pb2.ToRadio.ParseFromString`), a seconda del campo `payload_variant`:

| Campo ricevuto | Azione della radio finta |
|---|---|
| `want_config_id = N` | Avvia la sequenza di configurazione sotto, con `N` |
| `packet` (MeshPacket) | Registra in `received`; risponde con `queueStatus`; se `--ack` e `want_ack`, accoda un ack (vedi sotto) |
| `heartbeat` | Ignora (nessuna risposta) |
| `disconnect = true` | Chiude il socket di quel client |
| altro / vuoto / errore di parsing | Ignora e conta in `server.stats["ignored"]` (mai eccezione che chiude il server) |

**Sequenza di `FromRadio` inviata dopo `want_config_id = N`** (ogni frame = `0x94 0xC3 len_hi len_lo` + protobuf; `id` dei `FromRadio` progressivo da 1):

1. `my_info` (`MyNodeInfo`: `my_node_num`, `reboot_count=1`, `min_app_version=30200`, `device_id`, `pio_env="fake"`).
2. `metadata` (`DeviceMetadata`: `firmware_version="2.7.11.fake"`, `hw_model=HELTEC_V3`, `hasWifi=true`, `role=CLIENT`).
3. `node_info` del nodo proprio (`NodeInfo{num, user{id="!xxxxxxxx", long_name, short_name, hw_model, role}, last_heard, snr=0, is_favorite=false}`): **sempre**, anche con `want_config_id = 69420` (`NODELESS_WANT_CONFIG_ID`).
4. `channel` ×8, indici 0..7 (`Channel{index, role, settings{name, psk}}`): 0 = `PRIMARY` (nome vuoto, `psk = b"\x01"`), 1 = `SECONDARY` con nome configurabile (predefinito `"Amici"`, PSK fisso di 16 byte **finto** `bytes(range(16))`), 2..7 = `DISABLED`.
5. `config` ×8, nell'ordine: `device`, `position`, `power`, `network`, `display`, `lora` (`region=EU_868`, `modem_preset=LONG_FAST`, `hop_limit=3`, `use_preset=true`), `bluetooth`, `security` (vuoto: nessuna chiave).
6. `moduleConfig` ×13, nell'ordine: `mqtt`, `serial`, `external_notification`, `store_forward`, `range_test`, `telemetry`, `canned_message`, `audio`, `remote_hardware`, `neighbor_info`, `ambient_lighting`, `detection_sensor`, `paxcounter`.
7. `node_info` degli altri nodi (della sessione o sintetici), **solo se `N != 69420`**.
8. `config_complete_id = N`.

Dopo il punto 8 parte la **riproduzione** (se la sessione ha pacchetti): i `FromRadio{packet=MeshPacket}` escono secondo i tempi `t` della sessione / `speed`. Prima della configurazione completata non si inviano mai pacchetti di riproduzione.

**Risposta a un `ToRadio.packet`** (in quest'ordine, entro pochi ms):
1. `FromRadio{queue_status{res=0, free=15, maxlen=16, mesh_packet_id=pkt.id}}` (sempre).
2. Con `--ack` (predefinito spento) e `pkt.want_ack`: dopo `--ack-delay` secondi (predefinito 0,05) un `FromRadio{packet}` con `from = pkt.to` (se unicast; se `to == 0xFFFFFFFF` → `from = my_node_num`, "ack implicito" locale), `to = my_node_num`, `decoded{portnum=ROUTING_APP, request_id=pkt.id, payload=Routing(error_reason=NONE)}`, `id` nuovo, `rx_time` ora. `--nak REASON` (es. `NO_RESPONSE`) sostituisce l'errore (serve a provare "consegna fallita").

## Formato del file di sessione (versione 1) — definito in `tools/replay_record.py`

JSON lines, UTF-8, una riga = un oggetto, righe vuote e righe che iniziano con `#` ignorate.

```
{"format":"meshlens-session","version":1,"created":"2026-11-23T10:00:00Z","source":"db|radio|api|synthetic","my_node_num":2712847316,"channel_name":"Amici","note":""}
{"k":"node","b64":"<NodeInfo serializzato>"}              # 0..n, nodi per la configurazione (opzionale)
{"k":"config","b64":"<FromRadio serializzato>"}          # 0..n, solo da registrazione live (già ripulito dai segreti)
{"k":"pkt","t":0.0,"b64":"<FromRadio con packet serializzato>"}   # t = secondi dal primo pacchetto, non decrescente
```

Regole: la prima riga non vuota/non commento è l'intestazione, `version == 1` (altrimenti `SessionError("Versione di sessione non supportata: N")`); `k` sconosciuto → riga ignorata con avviso (compatibilità in avanti); `b64` non valido o protobuf non parsabile → `SessionError` con numero di riga (italiano). `t` obbligatorio per `pkt`, numero ≥ 0, non decrescente (altrimenti `SessionError`). `my_node_num` facoltativo (se assente la radio finta usa quello sintetico, predefinito `0xA1B2C3D4`, lo stesso di `T/test_radio.py`).

## Interfaccia pubblica di `tools/fake_radio.py`

```python
DEFAULT_PORT = 4404; FORBIDDEN_PORTS = (8686,)
START1, START2, HEADER_LEN, MAX_TO_FROM_RADIO_SIZE = 0x94, 0xC3, 4, 512
NODELESS_WANT_CONFIG_ID = 69420

def encode_frame(msg) -> bytes                      # 0x94 0xC3 + len BE + SerializeToString()  (ValueError se > 512)
class FrameDecoder:                                 # stesso comportamento del lettore della libreria
    def feed(self, data: bytes) -> list[bytes]      # restituisce i corpi completi; scarta i byte non-frame
def synthetic_nodes(my_num, count) -> list[mesh_pb2.NodeInfo]   # nodi finti con nome/posizione (coordinate in Italia) per `--nodes N`
def handshake_frames(cfg: FakeRadioConfig, want_config_id: int, session: Session | None) -> list[mesh_pb2.FromRadio]
                                                    # esattamente la sequenza dei punti 1-8; puro (nessun socket): testabile senza rete
@dataclass class FakeRadioConfig: host="127.0.0.1"; port=DEFAULT_PORT; my_node_num=0xA1B2C3D4; long_name="Radio finta"; short_name="FAKE";
                                  channel_name="Amici"; node_count=3; ack=False; ack_delay=0.05; nak=None; speed=1.0; loop=False;
                                  max_gap=5.0; restamp=True; restart_on_connect=False; sent_log=None
@dataclass class ReceivedPacket: time: float; client: int; packet: mesh_pb2.MeshPacket; text: str | None   # text = decoded.payload UTF-8 se TEXT_MESSAGE_APP
class FakeRadioServer:
    def __init__(self, cfg: FakeRadioConfig, session: Session | None = None)
    def start(self) -> None        # bind+listen (porta 0 ammessa), thread daemon di accept; non blocca
    def stop(self) -> None         # idempotente
    @property port -> int          # porta effettiva
    received: list[ReceivedPacket] # thread-safe (lock interno); copia con `received_snapshot()`
    stats: dict                    # {"clients": n, "handshakes": n, "frames_out": n, "ignored": n, "replayed": n}
    def push_packet(self, pkt: mesh_pb2.MeshPacket) -> None   # inietta subito un pacchetto "radio -> client" (per i test)
    def wait_handshake(self, timeout=5.0) -> bool
    def disconnect_clients(self) -> None                       # chiude i socket (prova di riconnessione)
def main(argv=None) -> int      # CLI: --session FILE --port N --host H --speed X --loop --nodes N --ack --nak REASON --max-gap S
                                #      --no-restamp --restart-on-connect --sent-log FILE --name NOME --my-num HEX --channel-name NOME -v
```

Riproduzione: un thread per server (non per client) mantiene il cursore globale sulla timeline; invia ai client "pronti" (che hanno ricevuto `config_complete`). Tempo di attesa tra i pacchetti `i-1` e `i` = `min((t_i − t_{i−1}) / speed, max_gap)` (se `speed == 0` o `inf`: nessuna attesa). `--loop` riparte dall'inizio al termine (con `id` pacchetto invariati: il dedup di MeshLens li scarterà, avvisato in documentazione). `restamp=True` riscrive `rx_time` con l'ora corrente all'invio. Se non c'è nessun client pronto il cursore **aspetta** (non perde pacchetti). `restart_on_connect=True` riporta il cursore a 0 a ogni nuovo handshake; altrimenti la riproduzione continua da dove era.

Un client alla volta è la norma (come il firmware), ma il server accetta più connessioni e le serve tutte (ognuna con il proprio buffer); `received` riporta l'indice del client.
