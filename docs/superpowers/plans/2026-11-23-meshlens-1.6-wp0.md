**Tech Stack:** Python 3 + FastAPI, sqlite3 (stdlib, FTS5), protobuf `meshtastic==2.7.11` (solo lettura); Svelte 5 + TypeScript + Vite + vitest.

**Spec:** `docs/superpowers/specs/2026-11-23-meshlens-1.6-design.md` (sezione "Organizzazione del lavoro", WP0). Mappa del codice: `docs/superpowers/research/2026-11-23-mappa-codice-1.6.md`. Fatti sulla libreria: `docs/superpowers/research/2026-11-23-ricerca-meshtastic-1.6.md`.
